## 2. Mechanismen

- **H** = Histaminhaltig | **L** = Liberator | **A** = Andere Amine | **B** = DAO-Blocker

### 🔑 Eherne Regeln:
1. **Alkohol = IMMER ≥ 2** (Ethanol = DAO-Blocker + Liberator. Klar = 2, nicht-klar/gereift = 3)
2. **Fermentiert ≥ 2** (je länger gereift, desto höher)
3. **Geräuchert/Gepökelt = 3**
4. **Frisches Fleisch/Fisch = 0** (nur tagesfrisch! Schwein = 1)

## 5. RAW vs COMPOSED

- **RAW** = Einzelne biologische Quelle (auch verarbeitet: Mehl, Öl, Saft, Flocken, Pulver, fermentiert aus EINER Quelle wie Käse/Joghurt/Wein)
- **COMPOSED** = Mehrere Zutaten kombiniert (Brot, Kuchen, Wurst, Pizza, Soße, Müsli, Schokolade)

## 6. Processing-Effekte

| Prozess | SIGHI |
|---|---|
| Trocknen, Gefrieren, Pasteurisieren | Gleicher Score |
| Erhitzen/Kochen | Gleicher Score (reduziert Risiko) |
| Räuchern | **0→3** |
| Pökeln | **0→2–3** |
| Fermentieren | **0→2–3** |
| Reifen (Käse) | **0→1–2** je nach Dauer |
| Destillieren | Alkohol bleibt 3 (Ethanol selbst = Liberator) |
